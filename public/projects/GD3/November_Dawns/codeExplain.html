Architecture d'Exploration Ren'Py

Spécification technique de l'agencement des calques et guide de scénarisation des pièces interactives.

1. Hiérarchie visuelle (La métaphore du théâtre)

L'affichage est découpé en quatre plans stricts d'arrière vers l'avant afin d'éviter tout chevauchement non maîtrisé entre décors, sprites et interface :

Plan Calque Ren'Py Contenu Rôle visuel
1. Fond master Fond noir uni / Shaders Arrière-plan global
2. Décor screens room_screen (viewport fixe) La pièce cadrée et ses zones cliquables
3. Acteurs front_sprites Sprites de personnages (show) Personnages positionnés devant la pièce
4. Régie overlay say, choix, quick_menu Interface prioritaire, toujours au premier plan
Règle pour le scénariste : Aucun calque n'est à spécifier dans les dialogues. Un simple show Eileen place automatiquement le personnage au bon niveau devant le décor sans masquer les boîtes de texte.

2. Configuration moteur

Dans options.rpy

define config.layers = [
    'master',           # Fond / Shaders
    'transient',        # Requis par le système Ren'Py
    'screens',          # room_screen (pièce interactive)
    'front_sprites',    # Personnages affichés devant la pièce
    'overlay'           # Dialogues, menus et alertes
]

init python:
    # Redirige les personnages vers le calque intermédiaire
    config.tag_layer["Eileen"] = "front_sprites"

    # Verrouille l'interface de dialogue sur le calque supérieur
    config.say_layer = "overlay"
    config.choice_layer = "overlay"

Dans screens.rpy

screen room_screen():
    zorder 10

    $ room_w = 1300
    $ room_h = 700
    $ dialogue_top_y = 840

    viewport:
        xsize room_w
        ysize room_h
        xalign 0.5
        yanchor 1.0
        ypos dialogue_top_y
        clips True

        imagemap:
            xfill True
            yfill True
            idle current_room.bg

            for h in current_room.hotspots:
                hotspot h.rect action h.action

screen say(who, what) layer "overlay":
    zorder 100
    style_prefix "say"
    window:
        id "window"
        # ... code say standard inchangé

screen quick_menu() layer "overlay":
    zorder 200
    # ... code quick_menu standard inchangé

3. Modèle de données (Classes)

init python:
    class Room():
        def __init__(self, id, bg):
            self.id = id
            self.bg = bg
            self.hotspots = []
            self.convos = []
            self.neighbors = []
            self.cinematic = None  # Label déclenché à la première visite

    class HotspotData:
        def __init__(self, rect, action):
            self.rect = rect      # Format: (x, y, largeur, hauteur)
            self.action = action  # ui.jumps("label_cible")

    class EventManager():
        def __init__(self):
            self.eventsObserved = set()

        def unlock(self, eventId):
            self.eventsObserved.add(eventId)

        def has(self, eventId):
            return eventId in self.eventsObserved

4. Déplacements (travel_to)

Le label travel_to orchestre les changements de lieu en assurant la transition, le nettoyage des acteurs précédents et le déclenchement d'éventuelles cinématiques :

label travel_to(destination):
    scene black with dissolve
    $ current_room = destination

    if current_room.cinematic is not None:
        $ cutscene = current_room.cinematic
        $ current_room.cinematic = None  # Consommée immédiatement
        call expression cutscene

    jump room_loop

label room_loop:
    call screen room_screen
    jump room_loop

5. Exemple de scénarisation (Style Ace Attorney)

Déclaration de l'environnement

init python:
    mgr = EventManager()

    # Déclaration des pièces
    bureau = Room("bureau", "backgrounds/bureau.png")
    archives = Room("archives", "backgrounds/archives.png")
    archives.cinematic = "premiere_visite_archives"

    # Hotspots du bureau
    spot_tiroir = HotspotData((200, 350, 180, 120), ui.jumps("inspect_drawer"))
    spot_porte  = HotspotData((50, 200, 120, 400), ui.jumps("aller_archives"))
    bureau.hotspots = [spot_tiroir, spot_porte]

    # Hotspots des archives
    spot_retour = HotspotData((50, 200, 120, 400), ui.jumps("aller_bureau"))
    archives.hotspots = [spot_retour]

Labels d'interaction (Fouille d'objets)

label inspect_drawer:
    show Eileen
    e "Voyons ce que contient ce vieux tiroir..."
    "Le tiroir s'ouvre : une lettre anonyme y est cachée."
    
    $ mgr.unlock("lettre_trouvee")
    
    e "Une pièce à conviction capitale ! Je la garde avec moi."
    hide Eileen with dissolve
    
    # Règle : toujours terminer un label d'interaction par un return
    return

Navigation par clic de porte

label aller_archives:
    call travel_to(archives)
    return

label aller_bureau:
    call travel_to(bureau)
    return

Changement de pièce en cours d'échange (Mid-dialogue)

label alerte_archives:
    show Eileen
    e "Tu as entendu ce fracas à l'instant ?"
    e "Ça provient tout droit de la salle d'archives... Suis-moi !"

    # Téléportation immédiate au cours de la scène
    call travel_to(archives)

    # La narration reprend aussitôt dans le nouvel environnement
    show Eileen
    e "Regarde tout ce désordre au sol... Quelqu'un est passé avant nous."
    hide Eileen with dissolve

    jump room_loop

Cinématique d'entrée automatique

label premiere_visite_archives:
    show Eileen
    e "L'air est glacial ici... Les documents ont été éparpillés."
    hide Eileen with dissolve
    return
